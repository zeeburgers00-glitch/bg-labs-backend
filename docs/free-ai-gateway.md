# Optional Vercel AI Gateway free-route chat

This is a text-only adapter, not an online video generator. It is disabled by default. With the deployment flag `VIMAX_GATEWAY_FREE_ENABLED=true`, the deployed function resolves a short-lived Vercel OIDC token **inside each request** using `@vercel/oidc`. The token is not stored in the database, returned to the browser, or logged. The Vercel project must have OIDC enabled. Existing Supabase authentication, owner allowlist, pause, history and daily attempt controls still apply.

The code fixes the model at `reflection/beam-free` and the Gateway host at `https://ai-gateway.vercel.sh`. It requires the Reflection provider and the `free` capability in the request, limits output, sends no tools, and does not request a fallback model. Before each generation it checks the fixed public endpoint catalog for the active free tag and zero published rates; failure stops the request. The server rejects a fallback provider when this free route is primary. A successful configuration status only means an OIDC token was available: account eligibility and an actual reply remain **unverified until a real authenticated test succeeds**. The provider can become unavailable or rate-limited; it is not unlimited.

## Cost review before enabling

The model's published Gateway inference prices were zero when reviewed on October 28, 2026, but providers can change them. The price check and free-model filter apply to the published model; they **cannot exclude a team-wide Bring Your Own Key (BYOK) credential** or separately billed Vercel add-ons. Gateway may prioritize an existing Reflection BYOK key and charge its provider account under that provider's own agreement; Gateway budgets generally do not cap BYOK spend. Team-level gateway policy, routing rules, add-ons and hosting charges can also matter, and a price check cannot eliminate races when prices or settings change. Review the team's BYOK and billable Gateway settings before enabling, and review again if they change. Never assume the attempt limits are dollar caps. No paid-model fallback is configured for this route.

1. Inspect the team's AI Gateway BYOK configuration and confirm no active Reflection provider key could be used, and check any paid Gateway add-ons or routing rules. The Arena Vercel connector does not expose that inventory; a Hobby hosting plan alone does not prove the Gateway is on its free tier. Do not delete or change another application's credentials or settings without approval.
2. Confirm the owner wants the privacy tradeoff below. Then set the nonsecret production flag `VIMAX_GATEWAY_FREE_ENABLED=true` and redeploy. Leave it false if the billing state is uncertain or the tradeoff is not accepted.
3. Sign in as an allowlisted user and send a nonsensitive message. A real request is needed to verify eligibility and service. If it fails, inspect the sanitized error, account verification requirements, model availability, and Vercel's documented limits. Do not paste tokens or prompts containing secrets into a support request.

**Privacy:** the chosen model sends each prompt and up to three recent turns through Vercel to Reflection. The provider does not advertise zero data retention or a no-training guarantee on this endpoint; messages and outputs may be retained or used for service/model improvement. Do not send passwords, API keys, confidential credentials or sensitive personal information. Supabase retains account chat history until deleted. Browser voice input/playback may use separate services.

## Dependency and test notes

`@vercel/oidc@4.0.4` is Apache-2.0 and used only by the Vercel wrapper; its request-context helper is called at request time. Its transitive `@vercel/cli-config` pins a Zod release affected by GHSA-mrhx-c7xc-m3w5, so the web package scopes an npm override to Zod `4.6.7`. Check dependency compatibility and run `npm audit --prefix web --omit=dev` after updates. Automated adapter and browser tests use fake tokens and mocked responses; they do not prove the real Gateway, billing or consent works.
