## Cross-cutting security and compatibility triage

The following are threat-model prompts, not claims of discovered vulnerabilities; none establishes that a source is safe. All unselected candidates require deeper code, dependency, licensing and runtime review before use.
- **YouTube automation:** Publishing and OAuth secrets have side effects; review permissions, content rights, provider quotas, and scheduling before use. Windows and hosted compatibility remain unverified unless specifically stated above.
- **AI agents & automation:** Agent instructions, MCP servers and tool calls may execute untrusted code; isolate execution, scope secrets, and bound provider spend. Windows and hosted compatibility remain unverified unless specifically stated above.
- **Voice & speech:** Voice cloning requires consent; verify model, data and voice licenses separately. Native model downloads and compute need review. Windows and hosted compatibility remain unverified unless specifically stated above.
- **AI video generation:** Model weights and code can have different licenses; GPU/VRAM, checkpoint provenance, cost and output rights need review. Windows and hosted compatibility remain unverified unless specifically stated above.
- **Images & thumbnails:** Model and asset rights, checkpoint provenance, untrusted extensions and GPU resource use require separate review. Windows and hosted compatibility remain unverified unless specifically stated above.
- **Video editing:** Native media parsers process untrusted files; sandbox inputs, bound CPU/memory and verify binary codec licenses. Windows and hosted compatibility remain unverified unless specifically stated above.
- **Local AI models:** Model weights have separate terms; limit model downloads, protect local endpoints and check RAM/VRAM requirements. Windows and hosted compatibility remain unverified unless specifically stated above.
- **Windows & computer control:** Desktop/browser control can access private data and perform actions; require isolation, least privilege and explicit user consent. Windows and hosted compatibility remain unverified unless specifically stated above.
- **Platform APIs:** User-authorized OAuth, official API permissions, content policy, quota and secret storage require review before any publishing. Windows and hosted compatibility remain unverified unless specifically stated above.
- **Discovery collections:** Collection entries are not individually audited or installed; inspect each linked project and its license independently. Windows and hosted compatibility remain unverified unless specifically stated above.

The requested `shotcut/shotcut` and `electron-vite/electron-vite` URLs returned 404. Similar-looking repositories exist, but have not been substituted, reviewed, or installed. `FlowiseAI/Flowise` and the original `rhasspy/piper` were archived when checked. The tested Piper package is its GPL successor, not the archived MIT project.

PySceneDetect/OpenCV wheel and transitive native-code licenses, including codecs, must be reviewed for the target platform before redistribution. The selected test used Linux, Python 3.11, PySceneDetect 0.7.2 and OpenCV 4.13.0.92; no Windows execution or hosted scene detection was tested.
