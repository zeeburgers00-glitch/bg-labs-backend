# ViMax AI provider setup and verification

As of 28 October 2026, ViMax has server-side text-chat adapters for Groq, Gemini, Z.ai, OpenRouter, Mistral, OpenAI, Hugging Face Inference and OpenCode Console. The optional Vercel/Reflection adapter is disabled by default. Pexels is a stock-search integration, not a chat model. Hacker AI remains unsupported because its customer-specific endpoint has not been independently verified.

**A configured key is not a successful provider response.** The checks in this change use simulated provider responses and do not verify a real credential, account entitlement, price or production inference. No live provider call was made by the implementation. Google sign-in remains a separate setup issue; use the existing email sign-in where available.

## Compatibility changes

- Groq's `openai/gpt-oss-120b` and `openai/gpt-oss-20b` now use `include_reasoning:false` and `reasoning_effort:low`; Groq documents that `reasoning_format` is not supported for GPT-OSS. The former `llama-3.1-8b-instant` default was retired for free and developer tiers on 16 August 2026; current source defaults include GPT-OSS and `qwen/qwen3.8-27b`. Owner-set `GROQ_MODELS` takes precedence and is not silently changed.
- Z.ai's `glm-4.7-flash` and `glm-4.5-flash` use non-thinking mode so the bounded test and normal chat can produce visible text. Z.ai lists both as free at the time of review, but access, availability and prices can change. This adapter uses the **general API**, not a separate coding-plan endpoint; a coding-plan credential may not authorize it.
- For OpenRouter `openrouter/free` and `:free` models, the request specifies zero prompt, completion and request price filters, sends no model fallback list, and the bridge refuses any automatic ViMax fallback. For `nvidia/nemotron-3.5-lightning:free`, reasoning is turned off to leave room for visible output. OpenRouter can choose an upstream provider, and its account-level BYOK/private-endpoint settings, fees and provider terms must be reviewed separately. A price filter is not a guarantee of zero charges. ViMax also refuses automatic fallback for the two Z.ai Flash models and Vercel Reflection Free.
- Some reasoning models need more than 16 tokens before returning visible text. The optional probe remains bounded to at most 1,024 output tokens for models where this is likely, including Groq GPT-OSS, Gemini, Hugging Face, OpenRouter's free router and OpenCode MiniMax M2.5/M2.7. Other probes use 16 output tokens. Input tokens may also be billed; a probe does not impose a monetary cap.
- HTTP errors are sanitized. A 401/403 suggests credentials or permissions; 429 suggests rate limits or quota. Other HTTP statuses are shown without provider response bodies, with a warning that processing or charges may have occurred. There is no automatic retry on ambiguous responses.

These adaptations do not grant provider access or guarantee model output. Do not infer video generation, uploads, voice or tool access from a working text-chat reply.

## Safely test from the hosted app

1. Rotate any provider keys previously exposed in chat. Enter replacements **privately** in the Vercel project's Sensitive Production environment variables, not in chat, client code or a repository. Check the provider's actual pricing, quota, account permissions, BYOK and privacy policies first. Redeploy after changing environment variables. Never overwrite unrelated credentials or the YouTube token-encryption key.
2. Sign in to ViMax, open **Chat settings**, and choose a configured provider and model. The **Provider setup status** section distinguishes missing/invalid configuration from a key that is merely present. An owner-controlled `*_MODELS` variable can restrict which models appear.
3. Select **Test selected provider**. Read and explicitly accept the confirmation. It sends the nonsensitive prompt “Reply with the word OK.” to the selected model; the provider's actual reply must contain text. The probe counts against ViMax's daily attempt limits, may consume input and output tokens, and may cost money even on failure or timeout. No ViMax fallback is attempted. If the cost or data terms are not acceptable, cancel instead of testing.
4. A success means only that this specific model returned text at that moment. The result is held in the current browser session, not treated as a permanent health guarantee or shared with another signed-in user. If it fails, review the displayed sanitized error and the provider dashboard; do not paste keys or private prompts into support messages. Do not retry an ambiguous timeout without accepting that the first call may have been billed.
5. Once a model responds, send a nonsensitive chat prompt. Chat sends the current prompt and up to three previous turns to the chosen provider; chat history is saved per user until deleted. A separately selected fallback on non-free routes may send that history to another provider and consume another attempt. The free-listed routes above cannot use automatic fallback.

OpenRouter may route prompts to other providers. The NVIDIA free endpoint's published notice says that usage is logged for security and product improvement and asks users not to upload confidential information or personal data. Read the actual provider's terms before use. Vercel Reflection has a separate retention/training disclosure in [free-ai-gateway.md](free-ai-gateway.md).

## Troubleshooting

- **No provider in the selector:** check Provider setup status, the production environment, owner allowlist and whether AI calls are paused. Deployment configuration only reports that a plausible server-side key and allowed model exist.
- **Credentials or permissions rejected:** privately rotate/check the provider key and its project, account, scopes and model access. Google OAuth credentials are not Gemini API keys, and a ChatGPT subscription is not an OpenAI API key.
- **Rate limit / quota:** check provider quotas and ViMax's 10 user / 50 shared daily attempt limits. These are attempts, not spending limits. A free model is neither unlimited nor guaranteed to be available.
- **HTTP 400/404/422 or no visible text:** verify the configured model ID and account access, and try another explicitly approved model. Reasoning, provider deprecation or small response limits can also prevent visible text. Do not enable an automatic paid fallback.
- **HTTP 402:** check the provider account balance and billing; do not add funds or run a paid model without the owner's informed approval.
- **Timeout / 5xx:** the request may have been processed and billed; ViMax does not automatically retry or switch provider in that ambiguous case.
