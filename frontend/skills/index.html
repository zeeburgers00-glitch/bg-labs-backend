            Worker setup and limits

            The worker runs separately on a trusted always-on machine, signs in as this account and uses server-side provider keys. Start it with npm run worker:planning after configuring the environment documented in the repository. Nothing runs continuously on Vercel. Stored jobs may remain queued when no worker is online.

            The queue allows up to 1,000 active jobs per account, subject to shared storage caps; this is not a tested throughput guarantee or 1,000 processes. Default provider budgets are 10 attempts per user and 50 globally per UTC day, with one provider call at a time per user. Pause stops new stages and requests cancellation of running jobs; an already-started call can finish or be billed.
