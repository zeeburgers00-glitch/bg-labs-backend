API

API Documentation

Integrate BG LABS into your apps with our RESTful API.

Authentication

All API requests require a Bearer token in the Authorization header.

Authorization: Bearer YOUR_API_KEY

Endpoints

POST/api/studio/generate
Generate TTS audio from text. Body: { text, voice, language, temperature, speed }
GET/api/auth/me
Get current user profile and credit info.
POST/api/auth/register
Register a new user. Body: { email, username, full_name, password }
POST/api/auth/login
Login. Body (form-urlencoded): username, password. Returns access_token.
GET/api/admin/stats
Admin: Get platform statistics.
GET/api/admin/users
Admin: Get all users list.

Code Examples

curl -X POST https://api.bglabs.io/api/studio/generate \\
  -H "Authorization: Bearer YOUR_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{"text":"Hello from BG LABS!","voice":"rachel"}'
import requests

resp = requests.post(
  'https://api.bglabs.io/api/studio/generate',
  headers={'Authorization': 'Bearer YOUR_KEY'},
  json={'text': 'Hello!', 'voice': 'rachel'}
)
const resp = await fetch('https://api.bglabs.io/api/studio/generate', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({text: 'Hello!', voice: 'rachel'})
});
